# Mesh chat park-native hosts

Canonical sources for the shared LiveChat / ChatApp browser hosts.

Published into **`relay-web-assets/assets/chat/`** by `relay-gateway/scripts/publish-web-assets.sh`.

Channel prefixes and ops log rooms: `relay-gateway/docs/RELAY_CHAT.md`.

| File | Role |
|------|------|
| `ChatCommon.host.js` | API/WS helpers, `scopedChannel`, CSS |
| `LiveChat.host.js` | Compact page embed |
| `ChatApp.host.js` | Full-page chat UI |
| `LiveChat.js` | CleverScript stub (`data-relay-park-native=fb-live-chat`) |
