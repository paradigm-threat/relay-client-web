Decentralized web stack

A mesh for git-backed sites

Relay hosts git-backed websites, CleverScript hooks, and peer gateways across a mesh of nodes. Open the client to browse repositories, or read how MyProblem is built on this network.

Open the client MyProblem

What the mesh hosts

Each node serves the same published repositories. The browser client at /app talks to whichever mirror answers.

Sites

Git-backed websites

Repositories publish as sites. The client lists them from the live catalog and opens each one in its own tab.

Hooks

CleverScript

Client hooks render in the browser through the Relay runtime, so a repo can ship its own page instead of a static export.

Nodes

Peer gateways

Gateways answer HTTP, share git state, and can cache content with IPFS. Add any node URL from the client.

Live mesh

These nodes are the public masters. The client probes them and shows which mirror is connected.

MyProblem is built on Relay

MyProblem is the product that runs the Relay way. No salaries, and no card expected. If the help was good, a person can reward the person who helped, the AI that helped, or both. Relay stays the mesh.
