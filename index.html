Relay

Relay is a decentralized Web3.0 stack and social network architecture. It hosts git-backed websites, CleverScript hooks, and peer gateways across a mesh of nodes.

Use this client to browse repositories and connected peers. Documentation and source live in the clevertree GitLab group.

  • relay-gateway — HTTP/git mesh node
  • relay-client-web — this browser client
  • CleverTree — project hub
